# Power BI – Customer Review & Marketplace Performance Dashboard

In an era where working smarter is just as important as working harder, I developed an automated Customer Review & Marketplace Performance Dashboard to transform manually collected business data into actionable insights.

The project is built around data that I personally collected, organised and maintained while working with customer engagement and marketplace operations across Amazon and Flipkart.

Rather than relying on repetitive manual reporting, I used **Google Antigravity** to develop an interactive dashboard, connected to an Excel data source and deployed through **Vercel**. This creates an automated reporting workflow where updates to the underlying dataset are reflected in the dashboard, reducing manual effort and making performance monitoring more efficient.

$ Key Features
- Customer review and rating analysis.
- Marketplace performance tracking across Amazon and Flipkart.
- Product-wise rating and review monitoring.
- Customer feedback and performance insights.
- Automated data updates from the connected Excel source.
- Interactive dashboard for easier data exploration and reporting.

$ Tools & Technologies
- Power BI / Business Intelligence
- Google Antigravity
- Microsoft Excel
- Vercel
- Data Collection & Management
- Dashboard Development & Automation

$ Project Objective
To simplify marketplace performance monitoring, reduce repetitive reporting tasks and turn raw customer engagement data into meaningful business insights.

**The idea behind the project:** Work smarter, automate repetitive processes and spend more time understanding what the data actually tells us.
